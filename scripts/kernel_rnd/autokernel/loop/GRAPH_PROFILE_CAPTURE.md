No launcher, model run or grade is included.

The actual writer UTC clock is retained per phase. Required order is owner recorded_at ≤ actual pre writer observation ≤ owner started_at ≤ owner observed_at ≤ actual during writer observation ≤ owner ended_at ≤ owner closed_at ≤ actual seal writer observation. Historical capture-window backfill refuses. Owner clocks, topology, execution phases and producer termination remain assertions to review, not independently proven facts.
