# Loop-owned oracle case sets

`<OP>/<name>.json` + `<name>.txt`: extra `test-backend-ops --test-file` cases for a target op, pinned by sha256,
with a path witness. Loaded by `evaluator/oracle_cases.py`. Candidates cannot edit these (they live in the research
repo); they exist because a candidate may not edit `tests/test-backend-ops.cpp`.

- `FLASH_ATTN_EXT/hd128-mask-absent`: hd128 FA, mask absent, Q f32 / K,V f16, heads 16/8 and 32/8, nb 512,
  kv 512/4096/16384 (generated by ak-surface-proof-b-20261106/gen_cases.py against C6 ggml.h). Witness = the
  gfx90a FA-v3 asm path log line (needs `GGML_HIP_FA_ASM_LOG=1`).
