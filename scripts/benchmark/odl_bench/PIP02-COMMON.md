# PIP-02 common native table scorer

Offline comparison of the frozen English 755-page, 243-table cohort; no inference. Both arms use OmniDocBench's native end-to-end table extraction, GT filtering/order, normalized-edit Hungarian matching, table normalization and TEDS in content and structure-only modes. Both are higher-is-better. Summary means are table-weighted; they are not the official page-weighted leaderboard aggregate. Extra predictions are excluded by the native GT-centric match. An explicitly complete empty output gives unmatched GT a native zero; unknown or damaged pages are undefined. Partial means are descriptive. Persisted comparison values remain null: per-attempt lineage verification and gate eligibility are not implemented yet, even if all pages complete. Joint full-population status requires both arms complete but does not establish adoption warrant. No quality threshold is added.

Run using the OmniDocBench interpreter with `PYTHONPATH=<research-worktree>/scripts/benchmark` and `python -m odl_bench.pip02_compare`, passing `--plan`, `--gt`, `--config`, `--image-root`, `--odl-root`, `--paddle-root`, `--pins`, `--pins-sha256`, and a new `--out-dir`. The plan and config have fixed prospective SHA-256 identities in code. For this cohort ODL root is `.../odl-batch-results`, Paddle root is `.../campaigns-fresh`. The CLI rechecks actual image digests for completed pages; ODL page/start/PDF/result/DONE/prediction links, Paddle campaign/page/start/result/markdown links, and all pinned bytes are verified. Invalid evidence is reported separately and treated as undefined. The journal establishes image and campaign identity, but the Paddle page journal does not itself bind the complete source snapshot to an individual result: its operator capture and regional provenance should be retained for audit. These unkeyed hashes detect accidental corruption, not a malicious actor able to rewrite all evidence.

The externally supplied pinned manifest must be SHA-256 checked by the CLI. It includes the executable, loaded Python modules and mapped native shared libraries, local OmniDocBench Python source, shared comparison implementation, and current producer source manifests; modules or shared libraries first loaded during scoring must also be covered or scoring fails. A host library loaded only after the second check during persistence is outside that dynamic check; preserve the environment. No result-dependent matching changes. The manifests and output files should be retained with the report. `compare-existing` is used as a persistence renderer, not as a scorer.

Results: `coverage-and-scores.json` includes per-page state and per-table scores, `row_set.json` provides scored rows with missing populations null, and `existing_comparison.{json,md}` is the existing comparison materialization. New output directory prevents replacement of prior reports. The ODL arm uses ODL 2.5 + Docling 2.91 on image-only PDF wrappers; no original-PDF claim. Paddle arm is native layout/recognition/assembly.

The write-side belief adapter should preserve run/source pins, GT/cohort identity, exact coverage, producer state, comparison artifacts and native per-table measurements as a native record, project to the shared `ClaimTuple`, and let `claim_tuple.grade()` decide. No new grading ladder or invented warrant. This code does not itself wire the belief writer.

**Known incomplete integration:** per-page results currently carry `source_lineage_verified: false`. Link original grants to the actual armed packets and their frozen source manifests, and link Paddle page finish to its originating capture only where the original evidence uniquely supports that inference; retain any ambiguous page as lineage-unverified. Do not treat present-day source files as a historical capture. This release provides observational scoring and is not a gate-ready delivery.
