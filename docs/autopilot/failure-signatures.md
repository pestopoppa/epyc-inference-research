AutoPilot records additive failure diagnostics in each native JSONL trial. This is source support only; it does not change SafetyGate, Pareto admission, accept/revert, baseline promotion, or context budgets.

`error_signature` version 1 records `stage=safety_gate`, sorted distinct machine `codes`, `species`, `action_type`, and integer `tier` (native tiers 0–3). The producer uses only actual failed, measured SafetyGate branches: `quality_floor`, `regression`, `per_suite_regression`, `routing_diversity`, and `throughput`. Passed/advisory categories, retry-not-revert outcomes, and unknown codes produce no identity. Prose, timestamps, paths, and trial IDs never define identity. Codes describe gate categories, not exception root causes or per-suite identity.

`error_scope` is separate: version 1, `comparability=COMPARABLE`, native evaluation `core_id`, recorded `infra_regime_digest`, and captured baseline `eval_quality_era` / `autopilot_speed_era`. Missing or unverified context stays null. This scope intentionally prevents comparison across instruments and infra regimes; it does not imply reproducibility or ratification.

`repeated_failures_prior` is a writer snapshot of the total prior matching failures in this journal's folded ledger. It is not a consecutive streak and excludes the current trial. Matching requires equal signature and explicit scope; corrupted, learning-excluded, explicitly `keep_revert_decision=excluded`, non-ok, successful/frontier, and unknown-identity/scope rows never count. Missing identity/scope yields unknown, never zero. Readers recount the folded ledger to honor later supersessions without rewriting the original snapshot.

Prompt cards render one compact typed line with species/action/tier, codes, `prior_total`, and a stable twelve-hex scope-content hash used only to distinguish displayed context groups. The scope hash is not a claim tuple or classifier; full context remains in the native record. Action groups retain the latest card for each identity/scope, including machine failures whose prose is empty. Version fields reject booleans; signatures/scopes require exact version-1 keys and primitive types. Unknown/ineligible entries avoid a ledger fold at append, and renderers reuse their existing folded history. Legacy failures retain bounded sanitized prose labeled `[unclassified]`. Negative evidence remains visible within existing trust filters and budgets. Loading old rows never creates a signature, scope, or counter. This diagnostic carrier introduces no measurement metric or grading ladder.
