# CS-8.STT5 public-anchor accuracy screen: prospective protocol

This plan precedes every scored run, including validation. It implements CS-8.STT5 at origin/main; rankings and rejection only, no production change. A later frozen input binding must record all actual dataset, derived-PCM, model, runner, code and settings hashes before that input is exposed. A missing binding or unknown result cannot produce an advancement verdict. No test-driven tuning or redraw is permitted.

CS-8.STT3 passing runners host their supported model families; a failed runner may host non-whisper arms, but its whisper outputs cannot be used. Frozen production whisper.cpp is always the baseline; do not use other runners' whisper rows before parity. Offline models never enter a streaming column.

## Settings and decoding

Freeze per-arm selection policy before validation and selected values before any test inference; input-binding amendment records every native command, decoder defaults, quant, context, prompt, language mode, model and binary hash. For frozen Whisper baseline and large-v3, the validation candidate grid is the singleton greedy temperature 0, beam 1, best-of 1, no temperature fallback, no prompt, VAD off, no flash attention; select this singleton absent an execution failure. Run forced language and auto separately. For the frozen in-tree Parakeet TDT v3 F16 runner, the validation grid is the singleton native default decode with automatic language identification, no prompt and CPU-only execution; its native CLI has no forced-language option. Validation failure or unsupported mode remains unknown, not an excuse to substitute test settings. CPU execution under build-role claims; production frozen tree used read-only with its own ggml library path and linkage proof.

## Scoring and decision

Use canonical CS-8.STT1/P-STT-1 scorer snapshot from research 99301fa149af86a6f9743d2b0405c9234ba39586. Raw manifests retain original reference, ordered hypotheses, PCM hashes, status, language, segment and runner metadata. Compute v1 and v2-candidate columns separately, unk counts and acoustic strata. Do not pool or difference across normalizers. For FLEURS, paired bootstrap resamples utterances within each language; for Earnings, resamples whole calls. Use 4,000 resamples and seed 146064415, derived as the integer value of the first eight SHA-256 hex digits of UTF-8 `codex3-cs8-stt5-accuracy-20261030-v1`, reporting candidate-minus-baseline percentage points and percentile 95% intervals; retain all denominator cases. Native crashes, timeouts and empty outputs count as full deletions when scored at an utterance unit; interrupted exposed cases with unknown result are retained and prevent definitive acceptance, never silently replayed. For released Earnings chunks, failed chunk hypothesis is empty, all chunks remain ordered in their parent and the whole-call reference remains the denominator. Record per-arm WER, n, CI, strata, unks, streaming delays and ranks.

An arm advances toward CS-8.STT6 iff paired 95% interval of WER difference vs production baseline is entirely below 0 in en or it and no gate language en/it/de/fr has lower bound above +1.0 percentage point. English-only arms advance only toward an English lane. Otherwise rank/reject once all required outcomes are known. No replacement or deployment decision occurs here.
