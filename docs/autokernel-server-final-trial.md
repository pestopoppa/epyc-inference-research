# Same-server correctness and parent-final native trials

The native server path retains original observations and produces a separate
parent-final record after the complete arm set exists. It does not rewrite an
earlier unknown finding, force anchor-first experimental order, or block a unit
completion waiting for an anchor that has not run yet.

## Original collection and independent anchor

`NativeServerT0WitnessAdapter` is a concrete correctness slot of
`ParentScientificWitnessAdapters.v2`. Its `owning_issuer` must be an actual
`NativeT0WitnessAdapter`. `register_owning_inputs` binds an original issued T0
artifact and its retained owning registry to the parent unit context, exact
per-slot evaluation requests, and a declared independent anchor unit.

The adapter reopens the original complete model-inventory receipt and its entry
file digest bridge, executable/DSO identity facts, raw server response bytes,
request identities, original lifecycle and parent readbacks. It does not rehash
the model during each measured unit. The original anchor must match the exact
source/binary/linkage triple, model inventory, prompt/request and slot identity;
matching only a current model or aggregate response digest is insufficient.

Each slot retains the full owning T0 report. Only original qualified static
evidence may be reused within its source/build/policy scope. Old CLI dynamic
coherence or dispatch cannot substitute for observations of the serving
instrument. The same-server generation variant cannot fall through to a CLI
runner, and subclasses are refused at that boundary.

## What the v1 server response proves

An explicitly greedy request can support the owning byte-coherence check against
an independently bound original anchor response. This is content-byte equality,
not generated-token trajectory equality. `token_agreement_ratio` and `seed`
remain `None`; tokens, seeds, traces and static reports are never synthesized.
Missing determinism, dispatch, state or other required gates remain unevaluated.
A passing byte-coherence gate is not a passing seventeen-gate T0 report.

Every response must fit its original warmup/measurement lifecycle interval.
When the original loaded instrument declares `parent_window_markers`, the
original `measurement_end` checkpoint is required and bounds measured responses.
Historical instruments without that declaration retain their older interval
contract. A marker declaration cannot be added retrospectively to fix missing
observations.

## Post-arm pair and final capture

1. Unit completion seals its immutable parent finding and artifact references.
   A candidate-first unit may legitimately retain unknown coherence then.
2. `IssuedNativeEvidenceRegistry.snapshot(plan=..., store=...)` requires the
   exact full ordered original unit set. `adapter.finalize_pair(...)` resolves
   the declared original anchors and replays the complete owning reports into
   a separate `ParentServerT0PairReference`.
3. `unified_worker.reopen_deferred_result(...)` performs the original bounded
   result/start/terminal/fence checks without callbacks and returns the typed
   result plus frozen capture payloads. It intentionally permits a completed
   fixed prefix for ordinary ingestion.
4. `adapter.final_trial_owner.finalize(...)` additionally requires every
   expected unit, lifecycle reference and both original v2 arm captures. It
   binds the original prepared/result/accepted-terminal/current-fence evidence
   and the exact original registry to a `ParentFinalTrialReference`.
5. `owner.reopen(reference, registry=..., store=...)` requires the actual
   original retained owner/registry and repeats the owning replay. It returns
   `ValidatedParentFinalTrial`, including typed T0 reports and the new final
   admissible view. A caller-constructed lookalike object is not an issuance.
6. `owner.captures(...)` produces two new v3 carriers. Native prevalidation
   reopens original and final evidence outside the controller mutex; the
   existing current-owner check and Journal transaction remain the append
   authority. The scientific pair alone cannot authorize capture.

`finalize` receives `prepared`, `start`, `terminal`, `result`, `fence`, `registry`
and `store` as keyword arguments. The result reader receives the first result
reference plus `prepared`, `start`, `terminal` and `fence`. The store and registry
must be the concrete original instances required by the owner; reopening files
does not reconstruct a lost original issuance registry.

## Immutable originals and source closure

Old v1/v2 artifacts, views and Journal rows remain unchanged. The final row
derivation changes only the newly established correctness witness, preserves
every original failed witness and rejected screen, and uses unchanged
`experiment_plan.admissible_units`. The original reason, value, terminal state,
order, artifact digest and other witnesses remain bound. Capture still requires
the existing contention, placement and GPU-residency warrants.

The original instrument prospectively pins the concrete scientific adapter,
configuration, original issuer and finalizer/source dependencies before plan
issuance. The child writer remains measurement_capture/v2; its closure is not
relabelled as the parent v3 writer. The finalizer's distinct closure is retained
under the scientific adapter's owning source pins.

The v3 carrier adds exactly `original_arm_capture` and `parent_final_trial` to
the v2 carrier fields. Its ID includes the final-trial digest, and its locator is
`parent-final-serving:{plan_digest}:{lineage_id}:{arm}:{final_digest}`. Journal
recognizes the closed shape and identity joins; original-issuance verification
still occurs at native prevalidation, not through JSON shape alone. Restart may
return the exact durable duplicate but does not restore a live grant or renew
eligibility for different bytes.

## Remaining scientific inputs

Control and calibration references currently remain explicitly `None` unless a
separate qualified owning issuance API is connected. A raw calibration solve is
not a qualified control. Full GLM trial readiness also requires actual qualified
static evidence, same-server dispatch/runtime linkage, any required state and
token-trajectory evidence, and concrete purpose/contention/residency warrants.
The retained response path does not invent these inputs or weaken the plan's
required witness list. Diagnostic final records remain diagnostic and do not
become measurement tuples merely because a post-arm pair exists.
