The contract is the actual ROOT module and the producer commit comes from this Git checkout; external opencode version and global configuration are test doubles.

The live caller audit found seat capture through `_call_record_v1`, and `BusPublisher` constructed by `run.py` and exercised through its send path. `claim._ensure_orchestrator_importable` serves `hold_cpu`, gpu-quiet and actor passthrough; `ak_check._orchestrator_root` serves the peer-region status check. Both resolve the orchestrator CPU-lock owner, accept a direct orchestrator checkout and support a linked ROOT worktree common directory. They do not load ROOT-owned code, so replacing their resolution with a ROOT validator would break that owner-path contract. GitNexus on the canonical index (older than the lane) reported LOW impact for all four entry points; direct source caller inspection supplemented it.
